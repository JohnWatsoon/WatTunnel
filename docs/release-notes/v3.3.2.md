**Open and close an auto tunnel's carriers from the main menu, and see their status there.**

The Kharej main menu now shows whether each auto tunnel's carriers are open or closed, and `c` switches them. Only the manager changed, so the engine does the same work as 3.3.1 and old and new peers work together. Run `wattun update` on each Kharej server to get the new menu; Iran servers see no change.

## Changes in detail

- **Carrier status on the main menu.** Each auto tunnel on Kharej gets a line under its row:
  - `open all 17 open · closes 5 min after Iran connects`
  - `open all 17 open · closes in about 3 min`
  - `open all 17 open · stays open until you close it`
  - `closed 1 of 17 open`
- **`c` on the main menu opens or closes the carriers.** If the server has several auto tunnels, it asks for the tunnel number.
  - Closing keeps only the carriers Iran is using and restarts the side that stays open, so its connections drop once. It refuses when Iran isn't connected, because it can't tell which carriers to keep.
  - Opening asks first, then opens every carrier and restarts the tunnel, so connections drop once.
- **What you open stays open.** A tunnel opened from the menu no longer closes itself after 5 minutes. It stays open until you close it, and closing hands it back to the automatic cleanup and safety net.
- **`u` on the tunnel page is the same switch.** It reads `Open carriers` or `Close carriers` depending on the state. It used to only close.
- **Commands unchanged.** `wattun-manager auto-widen NAME` and `auto-narrow NAME` still work. `auto-widen` doesn't hold the carriers open, so they close again after Iran's next stable pick.
