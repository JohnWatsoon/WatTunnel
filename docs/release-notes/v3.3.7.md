**Steadier tunnels under load, safer servers, and quotas that reset by day, week or month.**

This release collects 3.3.5, 3.3.6 and 3.3.7. The sender no longer holds up the receive side while it encrypts, a server takes up to 128 sessions instead of 32, quotas can reset on a schedule, and the manager shows the connection token as a QR code. Run `wattun update` on both servers. Old and new peers work together: nothing here needs both ends on the new version.

## Changes in detail

Engine
- **Encryption outside the session lock (3.3.7).** The sender used to encrypt up to 160 packets per round while holding the session lock, and the receive side waited behind it. It now builds packets under the lock and encrypts them after releasing it. Tested on the simulated-link suite and on a real Iran/Kharej pair (reverse `tcp`, 43-50 MB/s both ways, the path's limit there).
- **`WAT_DIRECT_WIN_MS` (3.3.7).** Sets how many milliseconds of data a direct `tcp`/`tls` tunnel keeps in flight (default 1000, unchanged). For tests only: on the Iran/Kharej pair 300 and 1000 gave the same speed and no clear change in round trip under upload (161-310 ms either way on an 88 ms route), so the default stays.
- **More sessions and connections (3.3.5).** `-max-sessions` (server, default 128, was a fixed 32) and `-max-conns` (client, default 4096).
- **Memory split per tunnel (3.3.6).** The default GC limit and stream budget are divided by the number of tunnel configs on the server (at least 256 MB and 64 MB each). An explicit `-mem-budget` or `GOMEMLIMIT` is left alone.
- **Quota periods (3.3.6).** `limits:` takes `period=day|week|month`, which resets a quota on the server's local clock. `/ports` shows `quota_period` and `quota_resets_at`.
- **`-decoy URL` (3.3.6).** On `ws`, `wss`, `h2`, `h2c` and `grpc`, requests that are not tunnel traffic are proxied to a real site. Refused when it points at the tunnel's own metrics address.
- **`[::1]` fallback (3.3.6).** When `127.0.0.1` refuses a forwarded TCP port, the server tries `[::1]` once, for services that listen only on IPv6 loopback.
- **`/stats?flat=1` (3.3.6).** One `key=value` per line, which the manager now reads (the JSON form stays the fallback).
- **Ports retry (3.3.5).** A public port that failed to open is retried every tick, not only after the next config edit.
- **Hedging (3.3.5).** `-hedge` now also covers small packets after the first 32 KB of a stream.
- **Restart safety (3.3.5).** Server packet numbers never start below the previous run's (`<config>.pn`).
- **Metrics hardening (3.3.5).** The metrics server refuses a non-loopback `Host` header, and `/carrier/toggle` accepts POST only.
- **Bonds (3.3.5).** A bonded server keeps one mute state for all sessions, new ones included.
- **Quieter logs (3.3.5).** Idle keepalives no longer print a stats line every 10 s. A warning appears when `-dns-listen` is not on a loopback address.

Manager and installer
- **Token QR code (3.3.6).** The manager shows the connection token as a QR code when `qrencode` is installed.
- **SLA minimum rate (3.3.5).** Uses kbit/s measured from the byte counters, and only while streams are open.
- **Heal (3.3.5).** Skips a tunnel with no metrics line instead of restarting it every 3 checks.
- **Update (3.3.5).** Keeps its temporary files in one private directory.
- **Config edits (3.3.5).** `set_value` no longer expands backslashes in the value.
- **Installer (3.3.5).** Sets no file capabilities on the binary and clears old ones.
