**Faster bonded tunnels, reversible Auto carrier cleanup (`o` on Kharej), multi-server reverse port blocks, signed offline Iran bundles, and IPv6 support in the manager.**

Run `wattun update` on both servers (or on Kharej run `wattun bundle`, copy `wattun-offline-amd64.tar.gz` to Iran, and run `wattun update --from wattun-offline-amd64.tar.gz`). The wire format is unchanged, so old and new peers interoperate during the upgrade. Existing 3.3.3–3.3.7 Kharej tunnels whose token was deleted after finalization automatically recover their token and `[o]` switch without needing to be deleted and recreated.

## Changes in detail

Engine (`wat/`, `cmd/wattun`)
- **Bonding window & late-ACK parity.** Bonded sessions (`PathChooser`) now enable `lateAck` and full stream window slack (`winSlack`) instead of falling back to single-ICMP defaults, preventing receive-window stalls when mixing legs with different RTTs.
- **Bond backpressure & connection-death repair.** `BondIO` and `MultiRaw` now implement `Backlogged()` (weighted across live unmuted legs via atomic `fullMask` tracking) and forward `ConnDeaths()` from pool and reverse-pool legs so frames queued on a dropped socket are repaired immediately instead of waiting on an RTO.
- **Dynamic mixed-bond pacing (`syncBondPacer`).** Pure-pool and mixed `icmp+pool` bonds pace in reliable mode while at least one pool leg is healthy, and automatically clamp back to `ICMPPathBps` if every pool leg dies and only `icmp` remains.
- **Multi-RTT `cwnd` sizing & mixed-MTU SWRR fairness.** `relV2` sizes `cwnd` by `max(minRTT, pathRTT)` and skips `probeRTT` window drains when bond path RTT spread exceeds `1.5 * minRTT`. `pathSet.choose()` awards SWRR credit to all healthy legs even when a burst packet exceeds a smaller leg's MTU, and `nextPath(false)` peeks the true next burst winner so `16 KB` pool legs and `1400 B` datagram legs each build right-sized packets without starving smaller-MTU legs.
- **Safe `NoDirect` MTU on CDN/HTTP carriers.** `ws`, `wss`, `h2`, `h2c` and `grpc` mark `Profile.NoDirect = true` in forward mode so bonded sessions keep 4 KB frames through Cloudflare/CDNs while `tcp`, `tls` and reverse pools use 16 KB frames.
- **Steady bonded pool connections.** Direct `tcp`/`tls` and reverse pool legs keep `SetKeepSlow(true)` inside bonds too (`cmd/wattun/main.go`), avoiding mid-transfer pool churn when traffic shifts across legs.

Manager & installer (`wattun-manager`, `install.sh`)
- **Reversible Kharej Auto cleanup & legacy token recovery.** `auto_finalize` now keeps `NAME.token` and `NAME.iranip` alongside `NAME.finalized`, raises the default `autoprune` grace window from 5 to 15 minutes, binds `o` (`open/close carriers`, with `c` kept as an alias) on Kharej's main menu, and rebuilds both `NAME.yml` and `NAME-r.yml` cleanly on `auto-widen` or after 3 failed health checks. Tunnels finalized under 3.3.3–3.3.7 recover their token automatically when opened in the dashboard, `wattun token NAME`, or key rotation.
- **Live active reverse measurement during `auto-test`.** Re-running `wattun auto-test NAME` (or `auto-retest`) on an Iran tunnel running a reverse carrier or reverse bond now measures the live tunnel via its own `/speedtest` instead of skipping its bound port and reporting `"Nothing worked"`, and hints to press `[o]` on Kharej when unused test ports are closed.
- **Custom reverse bonds (`c` and `b`).** The Auto test chooser now lets operators join `2+` reverse rows (with spaces, commas or `+`) into a reverse bond (`reverse: true` with per-leg `listen-<carrier>:` rules), offers `b` to bond all working reverse rows when fewer than two direct rows pass, and clearly explains why direct and reverse rows cannot be mixed.
- **Collision-free reverse port slices across multiple Kharej servers.** Each new Kharej Auto tunnel selects a free 10-port reverse slice in `30000..39990` instead of hardcoding `24431..24437`, allowing one Iran server to run reverse tunnels to multiple Kharej servers without port conflicts.
- **Signed offline bundles & persistent update proxy for Iran.** Added `wattun bundle [amd64|arm64]`, `wattun update --from <bundle.tar.gz|dir>`, offline RSA `SHA256SUMS.sig` verification in `install.sh`, interactive proxy/offline fallback when GitHub is unreachable, and Settings → `p` (`update-proxy` in `.manager.conf`) supporting both GitHub URL mirrors and `socks5h://` / `http://` proxies.
- **Inbound encryption guidance & IPv6 support.** Added a clear reminder in the Iran port editor and both READMEs that end-user panel inbounds must use TLS/Reality/Shadowsocks (not plain `VLESS + TCP header`), and unlocked IPv6 addresses (`[ipv6]:port`, bare IPv6, `::` dual-stack bind) across manager wizards, tokens, companions and validators.
