**Faster bonded tunnels, always-open unified Kharej Auto tunnels, random open port selection, `/unslop` TUI overhaul, signed offline Iran bundles, IPv6 manager support, and security/reliability fixes.**

Run `wattun update` on both servers (or on Kharej run `wattun bundle`, copy `wattun-offline-amd64.tar.gz` to Iran, and run `wattun update --from wattun-offline-amd64.tar.gz`). The wire format is unchanged, so old and new peers interoperate during the upgrade. Existing 3.3.3–3.3.7 Kharej Auto tunnels that were narrowed or finalized automatically reopen all planned carriers while preserving their `ports:` allowlist.

## Changes in detail

Engine & tools (`wat/`, `cmd/wattun`, `cmd/wprobe`)
- **Bonding throughput, MTU safety & pacing.** Bonded sessions (`PathChooser`) enable `lateAck` and full stream window slack (`winSlack`), forward pool backpressure (`Backlogged()`) and `ConnDeaths()` across `BondIO`/`MultiRaw`, pace mixed `icmp+pool` bonds at pool speed while a pool leg is healthy (clamping back to `ICMPPathBps` only when no uncapped leg remains), track `pathMinRTT` separately from `srtt` so `cwnd` and `probeRTT` handle multi-RTT bonds accurately, clamp `takeDgrams`/frames to `NextPath` `pathMTU`, propagate `Profile.NoDirect` through `mergeProfiles()` and `TCPPoolClient.Clone()` so HTTP carriers (`ws`/`wss`/`h2`/`h2c`/`grpc`) stay at 4 KB behind CDNs while `tcp`/`tls`/reverse pools use 16 KB, keep `SetKeepSlow(true)` on bonded pools, and award SWRR credit fairly across mixed-MTU legs.
- **Security & reliability hardening.** Capped `cmd/wprobe` server reply count (`k <= 8`) and payload size to prevent unauthenticated ICMP amplification; rejected invalid `-allow-ports` specs at startup and honored `/udp`-only explicit allowlists instead of falling back to `1-65535`; isolated untrusted reverse-pool connections before packet authentication; validated `parseSize` against `NaN`/`Inf`/overflow and rolled quota periods on config load; scaled server `alive()` window with `-ping-every`; and fixed `AF_PACKET` close races, `udpBatch` IPv6 handling, and `ProbeFakeMode` IPv6 dialing.

Manager, installer & TUI (`wattun-manager`, `install.sh`)
- **Always-open, single-tunnel Kharej Auto lifecycle.** Creating one Auto tunnel on Kharej now shows one unified tunnel `NAME` (aggregating stats, clients, traffic, start/stop/restart, ports, key rotation, and deletion across hidden `NAME-r` and `NAME-e-*` helpers). All test carriers stay open in the background automatically — removing `auto-narrow`, `auto-prune`, `auto-finalize`, manual `[o]`/`[c]`/`[u]` carrier toggles, and the interactive `3.3.0` extended prompt (`--extended` stays CLI-only) — while `heal()` continuously keeps `NAME-r` synced with Iran's IP (`auto_sync_companion`) and automatically reopens 3.3.3–3.3.7 narrowed/finalized tunnels.
- **Verified random open port selection.** Replaced hardcoded common ports (`80`, `443`, `8080`, `8443`, `4443`, `2053`, `123`, `4789`, etc.) with verified-free random high ports (`10000..32767`, below Linux's ephemeral range, checking `ss` + `/proc/net` fallback plus existing configs and tokens). When `--cdn-domain` (or CDN mode) is enabled, Cloudflare-proxied non-443/80 ports (`2053`, `2083`, `2087`, `2096`, `8443` for HTTPS; `2052`, `2082`, `2086`, `2095`, `8880`, `8080` for HTTP) are chosen instead, and `arm-blackout` uses explicit random open ports rather than grabbing `80/443/8443/53`.
- **TUI & installer polish (`/unslop`).** Replaced cluttered text walls and uneven chrome across `install.sh` and `wattun-manager` with the clean Kite + `WATTUN` mark, quiet neutral borders with one cyan accent, live download/probe gauges, and interactive GitHub-blocked proxy/bundle recovery in `install.sh`.
- **Custom reverse bonds, live reverse retests, offline bundles & IPv6.** Iran `auto-test`/`auto-retest` measures live reverse tunnels via `/speedtest`; `c`/`b` join `2+` reverse rows into reverse bonds; `wattun bundle` + `wattun update --from` + Settings → `p` provide RSA-verified offline/proxy updates; the Iran port editor warns against unencrypted panel inbounds; and IPv6 addresses (`[ipv6]:port`, bare IPv6, `::`) work across wizards, tokens, companions, and validators.
