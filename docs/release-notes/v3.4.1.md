**`wattun` now opens the new manager, written in Go and built into the binary.**

Run `wattun update` on each server you want it on; the wire format is unchanged, so one end can update before the other. Commands, keys, tunnels and config files are the same as before.

## Changes in detail

- **Go manager is the default.** `wattun` with no flags (or with a command such as `wattun status`, `wattun token NAME`, `wattun auto-test NAME`) runs the manager inside the binary, with the same menus, keys and commands as the bash manager. It was an opt-in preview in 3.4.0 (`WAT_GO_MGR=1`, no longer needed).
- **Bash manager still there.** `WAT_BASH_MGR=1 wattun`, or `wattun-manager` by its own name, opens the bash manager. The background jobs (the `wattun-heal` timer and bond retests) keep running `wattun-manager`.
