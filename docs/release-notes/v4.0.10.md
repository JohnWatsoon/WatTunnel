**Deleting a tunnel in the panel now deletes its Kharej side too, and a failed new tunnel no longer blocks its name.**

Only the Iran server (where the panel runs) needs this.

## Changes in detail

- **Delete reaches Kharej for every tunnel.** The "Also delete NAME on Kharej" box showed only for paired tunnels. Deleting any other tunnel in the panel removed only this server's side, and the Kharej side kept running. The box now also shows when exactly one Kharej has a tunnel of the same name, which is how the panel makes both sides.
- **A failed new tunnel cleans up after itself.** When "New tunnel on Kharej and here" failed after Kharej had made its side, that side stayed. The next try with the same name was then refused: *the name is already used on Kharej*. Now both sides are removed again, so you can retry with the same name.
- **Tunnels left over from before.** Tunnels that 4.0.9 and older left behind on Kharej stay until you delete them: Servers, the Kharej card, Delete on that row.
