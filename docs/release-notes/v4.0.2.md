**Change the carrier of a tunnel without testing again, and ptcp and spray are now in the carrier test.**

The panel keeps the result of the last carrier test, so switching to another carrier is a tick and a click. Update Iran for the switch. Update Kharej and create the auto tunnel again there to get ptcp and spray in the test.

## Changes in detail

- **Change carrier.** An Iran auto tunnel's drawer has a new Change carrier button. It shows the last carrier test with the carrier in use marked, and you tick the one you want (or several of one kind to bond them). Nothing is tested again. The manager now saves every finished test for this. Tunnels tested before 4.0.2 have no saved test yet: run Re-test carriers once.
- **"bad carrier label" fixed.** Switching from the carrier test card failed for labels with brackets, such as `l2tpv3 (shape only)`. Those labels now work.
- **ptcp and spray in the carrier test.** A new auto tunnel on Kharej (engine 3.4.3 or newer) now also listens on ptcp (one random TCP port) and spray (a random range of 1000 UDP ports), as hidden helpers like the extended carriers, with their firewall ports opened. Iran tests them in every preset. Tunnels made before 4.0.2 do not have them: create the auto tunnel again on Kharej. Both need Linux and root on both ends.
- **Carrier rows readable in a narrow window.** Long labels such as `l2tpv3 (shape only)` were cut to a few letters, and the row in use lost its label. The label now keeps its width.
