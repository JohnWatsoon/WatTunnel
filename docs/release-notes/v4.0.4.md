**Deleting a tunnel now removes it fully, on both servers.**

Two delete bugs could leave half a tunnel behind, and creating one with the same name then failed with "already used on Kharej". Update both ends.

## Changes in detail

- **Delete no longer leaves helpers running.** An auto tunnel on Kharej has helper units (`NAME-r` and up to 13 `NAME-e-*`). Delete stopped them one by one, about a second each, and the tunnel itself last. If auto-heal ran in that window, it saw the tunnel still up and started the helpers again, which then kept running (or restart-looping) without configs. Delete now stops the tunnel first, so auto-heal leaves its helpers alone. This covers delete from the console, the panel and the Kharej remote control.
- **Panel delete takes the Kharej side too, by default.** Deleting an Iran tunnel from the panel kept its Kharej side unless you ticked *Also delete on Kharej*, which was off. It is now on.
- **Clear message for a name taken on Kharej.** *New tunnel on Kharej and here* now says to pick another name, or to delete the one on Kharej first (Servers, the Kharej card, Delete on that row).
