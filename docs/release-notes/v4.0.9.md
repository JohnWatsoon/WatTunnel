**The panel sees new releases right away, and "Check for updates" replaces the Roll back button.**

Only the Iran server (where the panel runs) needs this. Once it runs 4.0.9, Update all updates Kharej from the panel as before.

## Changes in detail

- **Update all used an old release number.** The panel checked GitHub once at start-up and then every 6 hours. After 4.0.8 came out, the panel still said "latest release 4.0.7" while Kharej had already updated itself to 4.0.8, and Update all answered "This server is already on 4.0.7". Update all now asks GitHub fresh each time it runs.
- **Kharej's version counts.** The newest version the panel knows is now the newest of GitHub's answer and every Kharej's version. When Kharej already runs a newer release, this server shows "update available" even if GitHub is slow to answer from Iran.
- **Check for updates.** This button on the System page takes the Roll back button's place. It asks GitHub now and refreshes the Versions card. Rolling back is still in `wattun-manager` (Settings) and on the command line: `wattun rollback`.
